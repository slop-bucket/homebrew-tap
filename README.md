# slop-bucket Tap

## How do I install these formulae?

`brew install slop-bucket/tap/<formula>`

Or `brew tap slop-bucket/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "slop-bucket/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
